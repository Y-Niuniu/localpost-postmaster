## 二、启用自动派发前必须完成的验收（必须在**隔离的测试会话**里做）

1. 到达时绑定 A，随后把界面切到 B → 投递仍应落在 **A**
2. A 正在整轮运行时到达 → 必须**等这一轮结束**再投，不能插入当前轮
3. 关闭客户端 → 信件保持 pending，重开后不丢、不重复
4. 重复的 watcher 事件 → 只产生**一次**投递（幂等）
5. 丢失确认（写了但没收到 receipt）→ 标记为不确定，**不得**二次唤醒模型；靠显式回执对账

补充约束（来自 `docs/integration.md`）：跨崩溃的持久受理、原生守护进程启动、冷恢复、自动化均不在本交付内；
睡眠/关机暂停计算，锁屏本身不构成「已验证唤醒」。
